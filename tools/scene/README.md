# Тестовая сцена SCF (`tools/scene/`)

Набор `bat`-файлов для консоли Skyrim, который поднимает минимальную воспроизводимую сцену для
ручных тестов Summon Control Framework: чистая ячейка, два одновременных призыва, несколько
нейтральных и враждебных NPC.

Пункт плана: [`PLAN.md`](../../PLAN.md) §14, «Этап 0 — …маленькая тестовая сцена и `bat`-скрипты
для вызова двух призывов и нескольких NPC».

Сцена нужна, чтобы один и тот же набор проверок из [`TESTING.md`](../../TESTING.md) можно было
повторять после каждой сборки, не собирая бой вручную.

## 1. Состав

| Файл | Назначение |
|---|---|
| `scf_scene.txt` | основная сцена: `coc QASmoke`, god mode, перк «Парные души», два заклинания призыва, их экипировка, один нейтральный NPC, `scf status` |
| `scf_enemies.txt` | враждебные NPC (бандиты, драугр, волки); запускается отдельно, когда игрок уже осмотрелся |
| `scf_reset.txt` | уборка: убрать заспавненных NPC, выйти из тестовой ячейки, выключить `tgm`, снять добавленные заклинания и перк |

Это **исходники**: в игру они копируются, а не запускаются из репозитория.

## 2. Установка

Консольная команда `bat <имя>` читает файл из **каталога игры** (там, где лежит `SkyrimSE.exe`), а
не из `Data/`. Поэтому:

```powershell
# путь подставьте свой (у MO2 это папка игры, а не папка мода)
Copy-Item tools\scene\scf_scene.txt   'D:\Games\stb\Skyrim Special Edition\'
Copy-Item tools\scene\scf_enemies.txt 'D:\Games\stb\Skyrim Special Edition\'
Copy-Item tools\scene\scf_reset.txt   'D:\Games\stb\Skyrim Special Edition\'
```

Важные оговорки:

* Если используется **Root Builder**, файлы нужно класть не в реальный каталог игры, а в
  `Root/`-папку мода — иначе они исчезнут или будут перекрыты виртуальной файловой системой.
* Файлы в каталоге игры не отслеживаются Git: после правки исходника в репозитории его нужно
  скопировать заново.
* Кодировка файлов — чистый ASCII с CRLF. Не сохраняйте их в UTF-16/UTF-8-BOM: консоль тогда
  не прочитает команды.

## 3. Порядок прогона

1. Загрузите одноразовый тестовый сейв (см. риски в разделе 6).
2. В консоли: `bat scf_scene`.
   В QASmoke на игроке появятся два заклинания призыва и перк «Парные души».
3. Скастуйте **оба** призыва (в разных руках). В консоли `scf status` — отряд должен показать два
   отслеживаемых призыва; при лимите `uMaxSummonsPerOwner = 1` движок всё равно оставляет обоих
   (учёт SCF не опускается ниже росписи движка).
4. Поставьте нейтрального NPC (он уже в сцене) и выполните `bat scf_enemies`.
5. Прогоните нужные пункты из `TESTING.md` (см. раздел 4).
6. `bat scf_reset` — уборка и возврат в обычную локацию.

Если сцена «не поднялась», смотрите `SummonControlFramework.log` в
`Documents\My Games\Skyrim Special Edition\SKSE\` (или в логе профиля MO2): строки `[UpdateHook]`
показывают, увидел ли плагин призывы.

## 4. Какие проверки из `TESTING.md` удобно делать этой сценой

| Проверка | Почему сцена подходит |
|---|---|
| `TEST-ORDER-1` (Focus Target), `TEST-COMBAT-4`, `TEST-COMBAT-5`, `TEST-COMBAT-9` | враждебные NPC стоят кучно: удобно проверять фокус на одну цель и неизменность выбора |
| `TEST-COMBAT-6` (приказ завершается со смертью цели), `TEST-COMBAT-7` | драугр/бандит умирает предсказуемо, рядом есть вторая цель |
| `TEST-M2-1` (ассист), `TEST-M2-2` (радиус агрессии) | нейтральный NPC + враги в одном помещении: сразу видно, кого отряд игнорирует, а кого атакует |
| `TEST-M3-2` / `TEST-M3-3` / `TEST-M3-4` (команды «рывок»/«каст») | волки и огненный атронах в одной сцене, цель под прицелом рядом |
| `TEST-PASS-1` … `TEST-PASS-4` (прохождение сквозь друг друга) | два призыва одного владельца в тесном помещении без препятствий |
| `TEST-M1-1` (темпы следования, catch-up warp) | выход из QASmoke в открытую локацию на `coc Dragonsreach` |
| `TEST-STEALTH-1` … `3` (скрытность) | спокойные NPC в комнате: удобно подкрадываться, не отвлекаясь на чужой бой |
| `TEST-ORDER-8` (Guard + удары по подошедшему врагу) | врагов можно подвести/заспавнить по одному |
| **Индикатор FocusTarget через TrueHUD** (`PLAN.md` §14, Этап 8) | с TrueHUD в порядке загрузки `Numpad 1` по врагу должен добавить его info bar, сброс фокуса — убрать; без TrueHUD в `SummonControlFramework.log` будет ровно одна строка `[TrueHUDBackend] TrueHUD not found` |

Сцена **не** покрывает: постоянные призывы и воскрешение (`TEST-M4-*`), лимит `uPlayerSummonLimit`
(`TEST-M5-2`), сейв/лоад (`TEST-M4-3`), тестовый плагин Keyword API (`TEST-KW-*`), урон Friendly
Fire (`TEST-FF-*`) — для них нужны отдельные условия (несколько призывов сверх ванильного лимита,
второй актор-атакующий, отдельный ESP).

## 5. ID и команды, которые нужно перепроверить

Проверять FormID через houseCARL нельзя, а `skyrim.esm` в репозитории нет, поэтому часть значений
взята из памяти. В самих `.txt` они помечены `TODO(verify)`. Уверенность:

| Значение | Что это | Откуда | Как проверить |
|---|---|---|---|
| `000640B6` | Conjure Familiar | из постановки задачи | в консоли `help conjure 0` — найти строку `SPEL`, либо открыть `Skyrim.esm` в xEdit |
| `000204C3` | Conjure Flame Atronach | из постановки задачи | то же |
| `000581DE` | перк Twin Souls | `TESTING.md` §3/§5.2: подтверждён в игре именно с этим id | уже проверен в проекте; при сомнении `help "twin souls" 0` |
| `000D5F1C` | перк Twin Souls по постановке задачи | **не подтверждён**, в сцене не используется | если понадобится — `help "twin souls" 0` и сравнить с `000581DE` |
| `000A2C8E` | Lydia (нейтральный NPC) | из памяти | `help lydia 0` |
| `00037B8C` | Bandit | из памяти | `help bandit 0` (покажет `NPC_` записи с FormID) |
| `0001B0FB` | Draugr | из памяти | `help draugr 0` |
| `00023ABE` | Wolf | из памяти | `help wolf 0` |
| `coc QASmoke` | вход в тестовую ячейку | общепринятая практика, лично не проверялось | выполнить в консоли; при отказе — любая пустая interior-ячейка |
| `coc Dragonsreach` | выход из тестовой ячейки | из памяти | проверить; альтернатива — `coc HelgenKeep01` |
| `tgm`, `player.addspell`, `player.addperk`, `player.placeatme`, `player.removespell`, `player.removeperk`, `scf status` | базовые команды | используются в `TESTING.md` | — |
| `killall` | убрать всех заспавненных акторов | не проверялось | при отказе — выбрать актора и `kill` |
| `player.equipspell <id> left\|right` | экипировать заклинание | не проверялось, самая сомнительная строка | при отказе — экипировать вручную из меню магии (сцена от этого не ломается) |
| `startcombat player` | запасной способ сделать NPC враждебным | не проверялось | используется с выбранной в консоли целью |

Если ID неверный, падает только соответствующая строка: консоль печатает ошибку, остальные
команды выполняются. Отредактируйте `.txt` и скопируйте файл в игру заново.

## 6. Ограничения и риски

* **Сцена меняет сейв.** `player.addspell`, `player.addperk` и `tgm` остаются в сохранении.
  Используйте одноразовый тестовый сейв; `scf_reset.txt` снимает заклинания и перк.
* **Не запускайте `player.removeperk 000581DE` / `player.removespell …`**, если персонаж получил их
  честно до сцены — эти строки отберут настоящий перк/заклинание.
* `tgm` — переключатель. Если вы включили его сами, `scf_reset.txt` его выключит; при сомнении
  проверьте состояние до запуска.
* Два призыва требуют перка «Парные души» (или `uPlayerSummonLimit` в INI). Без него ванильный
  движок снимет первого призыва при касте второго — это не ошибка SCF.
* QASmoke — пустая техническая ячейка без навмеша и освещения: для проверок движения/строя она
  годится, для проверок поведения в реальном мире — нет; для них `coc Dragonsreach`.
* Файлы не входят ни в одну цель сборки (`xmake.lua`): их правка не влияет на DLL и на
  `scf_tests.exe`.

## 7. Статус проверки

Автоматических тестов у этих файлов нет. Проверено при создании: содержимое — ASCII, переводы
строк CRLF, `bat`-команды соответствуют именам файлов (`bat scf_scene`, `bat scf_enemies`,
`bat scf_reset`). **В игре сцена не запускалась** — все FormID и консольные команды из таблицы
раздела 5 остаются непроверенными до первого прогона.
